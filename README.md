## 七日杀服务端到底吃哪几项资源

CPU 看单核，不看核心数。七日杀服务端的逻辑跑在主线程上，一颗 3.4GHz 的老 E5 和一颗 5.8GHz 的 i9，后者能多带好几个人。核心数给到 4 核之后，再加核心对帧率的帮助很小。

内存 8G 是底线。原版地图、4 人左右，8G 够用；装 MOD 或者人数上到 6 人，16G 才稳。4G 内存能启动，但血月那种一堆僵尸同时刷的场景会直接卡死。

硬盘是新手最容易低估的一项。服务端本体约 15G，Windows 系统再占十几 G，30G 的盘装完就剩不下多少，存档和日志很快会把它填满。

带宽影响的是玩家进服时的地图同步。上传太小，人物加载到一半掉出地图的情况会反复出现。10Mbps 是起步，10 人以上给到 20Mbps 更稳。

## 开服流程：两条路，选一条走完

**面板路线（不用命令行）**

1. 买游戏云，进后台面板，新建实例时选 7 Days to Die 服务端
2. 填服务器名称和密码，设好人数上限
3. 启动实例，先看日志有没有报错，别急着进游戏
4. 在安全组放行服务端端口，TCP 和 UDP 都要放
5. 把「公网 IP:端口」发给朋友，对方在游戏里用「直接连接」填进去

**SteamCMD 路线（完整系统权限）**

1. 买 RCS，系统选 Windows Server，远程桌面连进去
2. 装 SteamCMD，建一个 `C:\steamcmd` 目录
3. 执行 `steamcmd +login anonymous +app_update 294420 validate +quit`，294420 就是七日杀服务端的 AppID，匿名登录即可下载
4. 打开服务端目录里的 serverconfig 文件，改服务器名、密码、地图种子
5. 系统防火墙和云平台安全组两处都放行端口
6. 启动程序，把 IP 和端口发出去

完全没接触过服务器的人，第一次走完这套流程大约 1 到 2 小时，时间主要花在下载服务端和等配置生效上。

## 连不上，按这个顺序查

**端口没放行**是最常见的原因，而且有两处：云平台的安全组，和服务器系统自带的防火墙。只放一处，外面照样连不进来。

**端口号对不对**。七日杀默认用 26900，部分版本还需要 26901 和 26902，以你服务端配置里写的为准。NAT 共享 IP 的套餐，还要在控制台把 26900 做一次端口映射，玩家连的是映射后的公网端口。

**房间名搜不到**。用房间列表检索有延迟，等几分钟不一定刷出来。直接让对方用「直接连接」输入 IP 和端口，比等列表快得多。

**服务端根本没起来**。面板上看日志，SteamCMD 路线的看控制台窗口，报错信息通常直接写明缺什么文件或者配置哪一行写错了。

更新之前先停服，把存档备份一份。面板一般自带备份功能，手动再复制一份存档目录也不费事。七日杀每次大版本更新都会改动服务端文件，直接覆盖更新有丢档的先例。

## 常见问题

**没有公网 IP 能开吗？**
能。买 NAT 共享 IP 的套餐，在控制台做端口映射就行，不需要独立公网 IP。只有 3 个人以下、又是临时玩几天，也可以用异地组网工具把几个人拉进同一个虚拟局域网，省掉买服务器的钱。

**2核4G 够几个人？**
原版地图、不开 MOD，2 到 3 个人稳定。4 个人同时在线打血月会开始卡。想留余量，直接上 8G。

**能不能先试再买？**
可以。1 元试用 1 天，先确认配置和延迟。正式买了不满意，7 天内可以自助退订，每个账号 3 次机会。但有条件：领过消费返利积分的不能退，日付、流量包、游戏云电量、硬盘或套餐升级这类非月付场景也不支持退订。

**更新会不会清档？**
不会自动清，但更新过程要停服，服务端文件被覆盖时配置有可能被重置。更新前备份存档目录，是唯一稳妥的做法。

**已经有云服务器还要买吗？**
不一定。手上如果有 2核4G 以上的云服务器，完全可以自己用 SteamCMD 装，代价是自己处理端口、防火墙和后续更新。买雨云的理由是省掉这部分工作量，以及国内机房对国内玩家的延迟优势。
